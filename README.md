# Northline Outlet storefront (source)

Static catalogue used by the Northline buying desk.

* `main` &mdash; current storefront.
* `snapshot-a` &mdash; storefront as captured at the previous price review.
* Product pages live in `catalog/<sku>.html` (file name is the lower-case SKU).
* The curated price watch list lives in `watchlist/ledger.json`.

Pages are viewed through GitHub's HTML preview service, for example:
`https://htmlpreview.github.io/?https://github.com/knobbyintens/filesystem_playwright_with_chunk_git_github_6466_pricewatch_f3b8e2/blob/main/catalog/ofc-1182.html`
